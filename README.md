# Invoice Data Wrangling

This notebook automates the extraction and compilation of data from multiple Excel and PDF invoice files. It processes payout summaries, order-level sales, and commission data, and compiles everything into a single Excel report.

### Output
The final output is an Excel file:

**`Final_Compiled_Report.xlsx`**  
with the following sheets:
- `Summary`
- `Payout Breakup Tab`
- `Order Level`
- `Commission Invoice`

 Sample data files are not included in this repository due to privacy reasons.
